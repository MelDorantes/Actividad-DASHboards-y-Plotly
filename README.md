# README – Actividad: Dashboards y Plotly

## Descripción General del Proyecto
Este proyecto implementa un dashboard interactivo utilizando Dash y Plotly, basado en un dataset de Kaggle. El objetivo es construir un sistema visual dinámico que muestre patrones y relaciones relevantes dentro de los datos.

## Dataset Seleccionado
**Marketing Campaign Dataset (Customer Personality Analysis)**  
Fuente: https://www.kaggle.com/datasets/imakash3011/customer-personality-analysis?resource=download&select=marketing_campaign.csv

## Visualizaciones Realizadas (10 Gráficos Plotly)
1. Histograma de edades con Rugplot  
2. Boxplot de ingresos por nivel educativo  
3. Scatter Edad vs Ingreso  
4. Distribución del gasto total por cliente  
5. Gasto promedio por categoría  
6. Pie chart de aceptación de campañas  
7. Heatmap de correlaciones  
8. Compras por canal  
9. Boxplot de gasto según estado civil  
10. Scatter quejas vs gasto  

## Esquemas de Color Utilizados
- Monocromático  
- Complementario  
- Triádico  

## Dashboard con Dash y Plotly
El archivo `app.py` implementa un dashboard interactivo que permite seleccionar entre los 10 gráficos y muestra una descripción debajo de cada uno.

## Instrucciones para Ejecutar
### Instalar dependencias
```
pip install dash plotly pandas numpy
```

### Ejecutar la app
```
python app.py
# python3 app.py # En caso de correr en MAC
```

Abrir en el navegador:  
`http://127.0.0.1:8050`
